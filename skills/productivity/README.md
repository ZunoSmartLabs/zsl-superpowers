# Productivity

General workflow tools, not code-specific.

- **[grill-me](./grill-me/SKILL.md)** — Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.
- **[handoff](./handoff/SKILL.md)** — Compact the current conversation into a handoff document so a fresh agent (or session) can continue cleanly. Saves to OS temp dir, redacts secrets.
- **[timesheet](./timesheet/SKILL.md)** — Summarize recent Claude Code sessions, Granola meetings and calendar events into timesheet bullets grouped by customer, then propose and log the matching Harvest entries.
- **[writing-great-skills](./writing-great-skills/SKILL.md)** — Principles and vocabulary for authoring great skills: progressive disclosure, sharp descriptions/triggers, when to bundle deterministic-gate scripts. Replaces the old `write-a-skill` process skill.
